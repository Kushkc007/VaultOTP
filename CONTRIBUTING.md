# Contributing to VaultOTP

Thanks for helping! This project values **small, auditable changes** over clever ones.

## Quick start

```bash
git clone <this repo>
cd vaultotp
npm install
npm test          # must be green before you send a PR
npm run dev       # http://localhost:4173
```

## Ground rules

1. **`src/app.html` is the source of truth.** Never edit `web/`, `mobile/www/`, `dist/` — they are generated by `npm run build`.
2. **No new runtime dependencies.** The app must keep working from a single file with zero network access. Dev-time tooling changes need a justification.
3. **No remote assets.** No CDN links, no external fonts, no analytics. `tests/repo.test.mjs` will fail the build if you add one.
4. **No `eval`, `new Function` or `document.write`.**
5. **Escape everything that reaches the DOM.** Use `escapeHTML()` for any interpolated string; never interpolate secrets into markup.
6. **Keep the crypto boring.** Use `crypto.subtle` — never hand-roll AES, KDFs or HMAC.
7. **Never commit secrets.** No keystores, no tokens, no real TOTP seeds — not even in tests or docs.

## What to change where

| You want to… | Touch |
|---|---|
| change UI, behaviour or crypto | `src/app.html` |
| change the Windows/macOS/Linux shell | `desktop/main.js`, `desktop/electron-builder.yml` |
| change Android packaging | `mobile/` (Capacitor config, `AndroidManifest.xml`, Gradle files) |
| change the build pipeline | `tools/*.mjs` |
| add a test | `tests/*.test.mjs` |
| update docs | `README.md`, `docs/` |

## Adding a feature — checklist

- [ ] Works in all three shells (browser, EXE, APK) or is explicitly platform-guarded.
- [ ] No new outbound requests.
- [ ] Secrets stay masked unless the user reveals them.
- [ ] State changes call `saveVault()` (which encrypts when a PIN is set).
- [ ] Keyboard + touch usable; `prefers-reduced-motion` respected.
- [ ] Tests still pass: `npm test`.
- [ ] Version bumped in `package.json` and `CHANGELOG.md` updated if user-visible.

## Commit style

Conventional-ish, imperative mood:

```
feat: add Steam Guard alphabet support
fix: keep timer in sync after "Next Code"
docs: clarify PIN recovery in FAQ
test: cover period-60 vectors
```

## Pull requests

* Keep PRs focused; one feature or fix per PR.
* Describe the **why**, and mention manual testing steps (which shell, which OS).
* Screenshots/GIFs for UI changes are appreciated.
* CI must pass (`ci.yml`).

## Translations

UI strings currently live inline in `src/app.html`. A localisation pass is on the roadmap — if you want to help, open an issue first so we can agree on the extraction format.

## Code of conduct

Be decent. Harassment, discrimination or publishing other people's secrets is not tolerated. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
